# 🧳 Tripflow

## Descripción

Tripflow es una webapp para planificar viajes y gestionar el presupuesto durante las vacaciones. Permite crear viajes, establecer un presupuesto, registrar gastos y monitorear cómo evoluciona el presupuesto durante el viaje.

La aplicación fue diseñada e implementada como parte de una prueba técnica, priorizando una experiencia simple, clara, accionable y responsive para desktop y mobile.

## 🚀 Ejecutar el proyecto localmente

### Requisitos

* Node.js 20 o superior
* npm

### 1. Clonar el repositorio

```bash
git clone https://github.com/SergioCC99/Tripflow.git
```

### 2. Entrar a la carpeta del proyecto

```bash
cd Tripflow
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar en desarrollo

```bash
npm run dev
```

La aplicación estará disponible en un localhost

## 📌 Información del proyecto

### Funcionalidades principales

* Creación de viajes y definición de presupuesto
* Dashboard de control de gastos
* Registro, edición y eliminación de gastos
* Control de gasto diario
* Categorías y métodos de pago
* Alertas de presupuesto
* Conversión de monedas
* Registro de gastos mediante voz
* Diseño responsive para desktop y mobile

### Datos

La aplicación no requiere backend. Los viajes y gastos se almacenan en `localStorage`, por lo que los datos permanecen en el navegador utilizado.

La aplicación incluye datos de ejemplo para facilitar la exploración de las funcionalidades.
